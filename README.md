# 🍳 Генератор случайных рецептов

Небольшое веб-приложение на Python и Django, которое хранит рецепты в базе SQLite и выбирает случайный рецепт с учётом фильтров.

## Описание

Приложение умеет:

- хранить рецепты в SQLite и показывать их в таблице;
- генерировать случайный рецепт с фильтрами по категории и максимальному времени приготовления;
- добавлять новые рецепты через форму и удалять существующие;
- вести журнал активности (генерация, добавление, удаление, ошибки, выход) и сохранять его в БД;
- рисовать график активности за последние 7 дней (Chart.js);
- показывать меню и завершать сеанс через пункт «Выход»;
- обрабатывать ошибки предметной области через собственные исключения.

Логика вынесена в классы (`ActivityLogger`, `RecipeRepository`, `RecipeGenerator`), представления сделаны на class-based views. Код покрыт тестами pytest.

## Требования

- Python 3.10 или новее
- pip
- Интернет для графика (Chart.js подключается с CDN)

## Инструкции по запуску

1. Перейдите в папку проекта:

   ```bash
   cd recipe_generator
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv .venv

   # Linux / macOS
   source .venv/bin/activate

   # Windows (PowerShell)
   .venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Примените миграции (создаётся файл `db.sqlite3`):

   ```bash
   python manage.py migrate
   ```

5. Запустите сервер:

   ```bash
   python manage.py runserver
   ```

6. Откройте в браузере http://127.0.0.1:8000/

Остановить сервер: `Ctrl+C`.

### Запуск тестов

```bash
pytest
```

Покрытие (опционально):

```bash
pip install pytest-cov
pytest --cov=recipes
```

## Краткая справка

### Как пользоваться

| Действие | Как сделать |
|----------|-------------|
| Получить случайный рецепт | Выберите категорию и/или макс. время, нажмите «🎲 Сгенерировать». Пустые фильтры означают «любой рецепт» |
| Добавить рецепт | Заполните форму в разделе «Добавить рецепт» и нажмите «Добавить» |
| Удалить рецепт | Кнопка «Удалить» в строке таблицы |
| Посмотреть историю | Раздел «Журнал активности» (последние 10 записей) |
| Завершить работу | Пункт меню «Выход» |

Категории рецептов: Завтрак, Суп, Основное блюдо, Десерт, Закуска.

### Маршруты

| Путь | Метод | Назначение |
|------|-------|------------|
| `/` | GET | Главная страница |
| `/add/` | POST | Добавление рецепта |
| `/generate/` | POST | Генерация случайного рецепта |
| `/delete/<pk>/` | POST | Удаление рецепта |
| `/api/activity/` | GET | JSON для графика: `labels` и `counts` |
| `/exit/` | GET | Страница прощания, запись `exit` в журнале |

### Собственные исключения

Все наследуются от `RecipeAppError`:

| Исключение | Когда возникает |
|------------|-----------------|
| `EmptyRecipeBaseError` | В базе нет рецептов |
| `NoMatchingRecipeError` | Под выбранные фильтры ничего не подходит |
| `InvalidRecipeDataError` | Некорректные данные рецепта |
| `DuplicateRecipeError` | Рецепт с таким названием уже есть (без учёта регистра) |
| `RecipeNotFoundError` | Рецепт для удаления не найден |

### Частые проблемы

- **403 при отправке формы**: в POST-форме нет `{% csrf_token %}`.
- **График не отображается**: нет доступа к интернету. Скачайте `chart.umd.min.js` в `recipes/static/` и подключите через `{% static %}`.
- **`Database access not allowed` в тестах**: тесту не хватает фикстуры `db` или маркера `@pytest.mark.django_db`.
